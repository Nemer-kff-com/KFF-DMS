# 10 — جهات المراسلة

كل إرسال يعتمد على بطاقة الجهة، لا على إدخال الرقم أو البريد في كل معاملة.

المسار: الإدارة → جهات المراسلة → إضافة / تعديل.

## الحقول المهمة للإرسال والخطاب

| الحقل | الغرض |
|--------|--------|
| الاسم عربي | اسم الجهة في القوائم والمعاملة |
| **اللقب** | حقل نص حر: سعادة، معالي، صاحب السمو… |
| **الاسم** | اسم المخاطب كما في الخطاب (بدون لقب أو تكريم) |
| **التكريم** | حفظه الله، حفظها الله، أو نص مخصص |
| الوظيفة | المسمى في الخطاب والطباعة |
| **رقم الجوال** | إرسال واتساب (`05…` يتحول إلى `966…`) |
| **البريد الإلكتروني** | إرسال الخطاب عبر SMTP |
| هاتف أرضي | اختياري؛ إن لم يُعبَّأ الجوال يُستخدم الهاتف إن كان رقم جوال |

## التجميع في الخطاب

```
اللقب + الاسم + التكريم
```

مثال:

`سعادة الأستاذ أحمد العلي حفظه الله`

في نص الصادر الجماعي:

- `{title}` أو `{title_prefix}` — اللقب فقط
- `{name}` — الاسم فقط
- `{honorific}` — التكريم فقط
- `{honored_name}` — اللقب + الاسم + التكريم
- `{job}` `{number}` `{date}` `{subject}`

## ترحيل البيانات القديمة

إذا كان حقل «الاسم» القديم يحتوي اللقب معاً (مثل «سعادة أحمد»)، يُفصل تلقائياً عند أول تشغيل إلى **لقب** + **اسم**.

## قائمة الجهات في الإدارة

`admin/entities.php` — الأعمدة مدموجة لتقليل عرض الجدول:

| العمود | المحتوى |
|--------|---------|
| **#** | ترتيب العرض، يُعاد ترقيمه مع الصفحة والبحث (ليس `id`) |
| **الاسم** | اللقب بخط صغير فوق الاسم، ثم التكريم أسفله بمحاذاة يسار |
| **جهة العمل** | الوظيفة بخط صغير فوق اسم الجهة |
| **النطاق** | رمز مع تلميح: 🌐 جهة عامة، 🏢 جهة قسم (يظهر اسم القسم في التلميح) |
| **التواصل** | الجوال والبريد، كل منهما في سطر؛ تبقى الخلية فارغة إن لم يوجد شيء |

- تعرض **20 جهة في الصفحة**؛ البحث يُنفَّذ على الخادم ويشمل الاسم والوظيفة والجوال والبريد والعنوان والملاحظات واسم القسم.
- نص البحث ينتقل تلقائياً إلى **التصدير والطباعة**، فتحصل على نفس النتائج المعروضة.

## اختيار الجهة في نموذج المراسلة

الحقل قائمة منبثقة بالبحث، لا قائمة منسدلة. **لا تُحمَّل الجهات مع الصفحة**، بل تُجلب أول 25 نتيجة من `api/entities_search.php` عند فتح القائمة أو الكتابة فيها — راجع [17-scalability.md](17-scalability.md).

- **الصادر** يُحفظ باسم الشخص (`directed_to`)، و**الوارد** باسم جهة العمل (`name_ar`).
- ترتيب الأعمدة في القائمة: الاسم، ثم الوظيفة وجهة العمل، ثم النطاق، ثم التواصل.
