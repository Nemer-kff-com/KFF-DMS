# 12 — إرسال الصادر بالبريد وواتساب

## صادر مفرد

من صفحة عرض الصادر (`outgoing/view.php`):

1. بطاقة **إرسال الخطاب** تعرض اسم الجهة مع التكريم، البريد، والجوال.
2. **إرسال بالبريد** يرسل رسالة HTML فيها الرقم والتاريخ والموضوع ورابط التحقق.
3. **إرسال واتساب** يرسل قالباً معتمداً إن وُجد، وإلا نصاً يتضمن نفس البيانات.
4. **إرسال بالبريد** و/أو **إرسال واتساب** من بطاقة «إرسال الخطاب».
5. آخر محاولة تظهر تحت كل قناة: تم الإرسال / فشل / بلا بيانات.

> **التسليم** لم يعد في هذه البطاقة — انتقل إلى **التسليم والحالة → التسليم** في [09-outgoing-receipt.md](09-outgoing-receipt.md).

## صادر جماعي

من نتائج الدفعة (`outgoing/batch.php`):

1. حدّد المستلمين (تحديد الكل أو صفوف محددة) ثم **إرسال المحدد بالبريد** أو **إرسال المحدد واتساب**.
2. كل عضو محدد يُرسل إليه برقمه ورابطه واسمه وتكريمه.
3. من بلا بريد أو جوال يُتخطى ولا يوقف الباقي.
4. الجدول يعرض حالة آخر إرسال لكل عضو.
5. **طباعة المرسل إليهم** تفتح كشفاً للعرض والطباعة (اسم، وظيفة، رقم صادر، جوال، بريد، وحالة الحضور إن وُجدت).
6. **طباعة الخطابات** تطبع خطاباً مستقلاً لكل مستلم.

## ماذا تحتوي الرسالة؟

- تحية والسلام عليكم
- الاسم مع التكريم
- **نص الخطاب** كما كُتب في الصادر الجماعي (مع استبدال الاسم والتكريم والرقم)
- رقم الصادر والتاريخ
- رابط صفحة التحقق (`verify.php?token=...`) — نفس رابط QR

لا يُخلط رمز التحقق مع أي رمز آخر. الرسالة إشعار رسمي بالخطاب، والتحقق من الصفحة العامة.

**المرفقات:** عند الإرسال بالبريد تُرفق ملفات المعاملة من «الوثائق المرفقة» (ما عدا مرفقات الإقفال).

## السجل

كل محاولة تُحفظ في `tblcorr_deliveries`: القناة، المستلم، النتيجة، الخطأ إن وُجد، والمستخدم.

يُسجَّل أيضاً في سجل النشاط: `send_email` / `send_whatsapp`.

## أعطال شائعة

| العرض | السبب الأرجح |
|--------|----------------|
| الزر معطّل | القناة غير مفعّلة أو الجهة بلا بريد/جوال |
| فشل SMTP مصادقة | كلمة مرور تطبيق / عدم تطابق المستخدم مع البريد المرسل |
| فشل واتساب قالب | اسم القالب أو متغيراته لا تطابق ما هو معتمد لدى Meta/Twilio |
| رقم مرفوض | الجوال ليس بصيغة قابلة للتحويل إلى دولي |
