# مساعدة سريعة

| ماذا تريد؟ | أين؟ |
|------------|------|
| خطاب وارد | **الوارد** ← وارد جديد |
| خطاب صادر | **الصادر** ← صادر جديد |
| مراسلة بين قسمين | **المعاملات الداخلية** |
| تعميم داخلي | **التعاميم** |
| جهات الاستلام | **جهات المراسلة** |
| ما يحتاج قرارك | **يحتاج إجراء** |
| إحالة بين الأقسام | عرض الوارد/الداخلي ← **سجل الإحالات** — أو قائمة **الإحالات** |

## بعد الحفظ

من صفحة المعاملة: مرفقات، طباعة، إحالة، تعليقات، ثم إقفال عند الانتهاء.

## الصادر فقط

- **إرسال** بالبريد أو واتساب إن كان إلكترونياً
- **استلام** عند التسليم الورقي
- **إلغاء / سحب** عند الحاجة

## مهم

- المعاملة **السرية** لا يراها زميل القسم إلا إذا كان مخوّلاً
- الرقم يُنشأ تلقائياً عند الحفظ
