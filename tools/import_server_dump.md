# استيراد جهات + وارد/صادر من نسخة السيرفر

يُبقي قاعدة النظام الحالية (مستخدمون، أدوار، إعدادات…) ويستورد فقط بيانات المراسلات من ملف SQL.

## قبل التشغيل

1. خذ نسخة من السيرفر: `dms-server.sql` (mysqldump).
2. انسخ مجلد المرفقات من السيرفر إلى مسار التخزين المحلي المعرّف في الإعدادات (`storage_root`)، مثل:
   - `D:/dms-data/uploads/incoming/…`
   - `D:/dms-data/uploads/outgoing/…`
   - `D:/dms-data/uploads/receipts/…`
3. تأكد أن أقسام النظام المحلي تطابق أرقام أقسام السيرفر إن أمكن (أو راجع `department_id` بعد الاستيراد).

## التشغيل

من جذر المشروع:

```bat
C:\xampp\php\php.exe tools\import_server_dump.php C:\1\dms-server.sql
```

## ماذا يفعل السكربت

| الخطوة | الإجراء |
|--------|---------|
| جهات المراسلة | استبدال `tblentities` |
| الوارد والصادر | استبدال صفوف `incoming` / `outgoing` فقط |
| الاعتماد | `approved` → شارة «معتمد»؛ بدون اختراع صاحب قرار؛ تصفير `assignee` |
| المرفقات | استيراد `tbldocuments` و `tblcorr_attachments` المرتبطة |

### اعتماد المعاملات القديمة (مهم لعمود الاعتماد في القوائم)

- الشارة: **معتمد** (الصادر والوارد) — ليست «الاتصالات».
- الاسم تحت الشارة يظهر فقط إن وُجد `issue_approval_decided_by` حقيقي في المصدر.
- لا يُنسخ المنشئ ولا مدير النظام كصاحب قرار تلقائياً.
- `issue_approval_assignee_id` يُصفَّر حتى لا تُعرض كمسار طباعة اتصالات.

لا يستورد: الداخلي، المستخدمين، الإعدادات، الأرشيف، التعاميم.

## بعد التشغيل

- افتح قائمة الوارد/الصادر: الحالة **معتمد**، والاسم تحتها فقط إن وُجد قرار حقيقي.
- افتح معاملة بمرفق وتأكد أن الملف يفتح من `storage_root`.
