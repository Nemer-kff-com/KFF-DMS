# 14 — دليل الأدوار والصلاحيات

## الهدف

يوضّح هذا الملف صلاحيات الأدوار في نظام الصادر والوارد، مع تركيز على **مشرف الأرشيف** (`archive`) كبوابة استقبال مركزية، وعلى صلاحيات السرية ودورة الاعتماد.

المراجع: `config/auth.php`، `config/permissions.php`، صفحات `admin/roles.php` و`admin/permissions.php`. كثير من الأزرار تُفحص بـ `user_can('…')` وليس برمز الدور وحده.

---

## الأدوار الأساسية

| الرمز | الغرض العام |
|-------|-------------|
| `admin` | مدير النظام — إعدادات كاملة، مستخدمون، تجاوز مسار عند التعطّل، مساعدة النظام |
| `communications` | اتصالات / إرسال وطباعة وتوزيع حسب الصلاحيات الممنوحة |
| `archive` | أرشفة وتشغيل؛ غالباً بوابة وارد مركزية إن مُنحت `corr.any_department` |
| `department` | إدخال ومعالجة معاملات **قسمه** فقط |
| `viewer` | عرض فقط، بدون تعديل |

يمكن ضبط مصفوفة الصلاحيات لكل دور من الواجهة؛ الجداول أدناه تعكس السلوك الافتراضي الشائع وليست بديلاً عن صفحة الصلاحيات.

## دوال الصلاحيات (مرجع سريع)

| الدالة | المعنى الحالي |
|--------|----------------|
| `can_edit_correspondence()` | أدوار تشغيلية + فحص `*.edit` عند الحاجة |
| `can_choose_correspondence_department()` | عبر `user_can('corr.any_department')` (غالباً أرشيف/مدير) |
| `can_view_all_departments()` | مدير، أرشيف، مشاهد (وما شابه حسب الإعداد) |
| `can_delete()` | مدير وأرشيف عادةً — حذف المرفقات الحساس |
| `can_manage_users()` | مدير النظام فقط |
| `dms_user_is_system_admin()` | دور admin أو دور مُعلَّم كمدير نظام |

## صلاحيات مشرف الأرشيف — ملخص

| الفئة | مسموح | ممنوع |
|-------|-------|-------|
| **الوارد والصادر** | تسجيل، تعديل، إحالة، تعليقات، تغيير الحالة، ربط وارد↔صادر | — |
| **نطاق الأقسام** | يرى **كل** الأقسام؛ يختار القسم عند التسجيل | — |
| **المرفقات** | رفع وحذف مرفقات المعاملات | — |
| **سند استلام الصادر** | تسجيل بيانات التسليم | — |
| **الإرسال** | بريد / واتساب (إن ضُبطت الإعدادات) | ضبط SMTP أو واتساب |
| **أرشيف الوثائق** | إضافة، تعديل، حذف وثائق وملفات الأرشيف | — |
| **بيانات النظام** | جهات، مجموعات، قوالب، تصنيفات، أنواع أرشيف | مستخدمون، أقسام، إعدادات الجهة/السرية |
| **السجلات والأمان** | — | سجل النشاط، سجل الأمان، الجلسات النشطة |
| **المساعدة** | — | `admin/help.php` لمدير النظام فقط |

## السرية وصلاحيات `view.confidential.*`

ليست صلاحية واحدة: لكل نوع رمز مستقل (وارد / صادر / داخلي / أرشيف عام / منح / مشاريع / مالية).

| الأثر | من يشمله |
|--------|----------|
| **رؤية** العنصر السري في القوائم والفتح | المنشئ، مخوّلو المسار (إسناد)، من لديه `view.confidential.{type}`، مدير النظام |
| **فتح الملفات** السرية | نفس الاستثناءات العليا + من يسمح له إعداد `conf_attach_*` أو تجاوز المعاملة؛ المنع يغلب عند تعدد الأدوار |
| زميل القسم بلا صفة أعلاه | **لا يرى** السري إن كان تقييد الرؤية مفعّلاً |

الضبط العام: `admin/confidential_settings.php`. التجاوز لكل عنصر: زر القفل بجانب حقل السرية.  
المرجع: [25-confidential-correspondence.md](25-confidential-correspondence.md) · دورة الاعتماد: [24-approval-workflow.md](24-approval-workflow.md).

> ملاحظة: تسمية الصلاحية في الواجهة قد تذكر «المرفقات السرية»، لكنها تُستخدم أيضاً لرؤية المعاملة/الوثيقة السرية (الطبقة A) وليس للملفات فقط.

## دور مشرف الأرشيف في استقبال الوارد

```
خطاب يصل فعلياً
        ↓
مشرف الأرشيف يسجّل «وارد جديد»
        ↓
يختار القسم المختص من القائمة (أي قسم)
        ↓
يرفع مسح الخطاب (PDF/صورة) — يُفضّل عند التسجيل، ويمكن تأجيله إن كان الظرف مغلقاً ثم الرفع من صفحة العرض
        ↓
النظام يمنح رقم و/YYYY/###### + QR
        ↓
إحالة للقسم إن لزم + متابعة الحالة
```

**الفرق عن مشرف القسم:** مشرف القسم يُسجّل الوارد **لقسمه فقط** ولا يرى إلا معاملات نطاقه. مشرف الأرشيف يرى **الكل** ويختار القسم المناسب — مناسب **لمكتب الوارد المركزي**.

## ملاحظات تشغيلية

1. **حساب الأرشيف** لاستقبال كل الأقسام يحتاج صلاحية `corr.any_department` (وليس مجرد رمز الدور).
2. **حذف المرفقات** صلاحية حساسة؛ غالباً المدير والأرشيف عبر `can_delete()`.
3. **المشاهد** يرى نطاقه حسب الصلاحيات لكن لا يعدّل — مناسب للتدقيق.
4. **مشرف القسم** بدون `department_id` لا يستطيع إنشاء معاملات (`corr.department_account_required`).
5. داخل دورة الاعتماد: المراجع/المعتمد لا يعدّلان؛ القفل للمنشئ ومدير النظام — [24-approval-workflow.md](24-approval-workflow.md).
6. السرية **لا تُورَّث** بالانتقال لقسم جديد ولا بالنيابة تلقائياً — [25-confidential-correspondence.md](25-confidential-correspondence.md).
