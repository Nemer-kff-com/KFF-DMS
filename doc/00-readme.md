# نظام الصادر والوارد (DMS) — مؤسسة الملك فيصل

بدء سريع للنظام. التثبيت التفصيلي في [02-installation.md](02-installation.md)، والفهرس الكامل في [README.md](README.md).

## المتطلبات

- XAMPP (Apache + MySQL + PHP 8+)
- تفعيل امتدادات PHP: `pdo_mysql`, `fileinfo`

## التثبيت السريع

1. ضع المشروع في `C:\xampp\htdocs\dms`
2. شغّل Apache و MySQL من لوحة XAMPP
3. إن لم تكن القاعدة مثبتة بعد: انسخ المثبّت مؤقتاً من `C:\backup\dms-install` إلى `dms/install/` ثم افتح http://localhost/dms/install/ واضغط **تثبيت الآن**، ثم أعد نقل/حذف `install/` خارج المشروع
4. سجّل الدخول بحساب مدير النظام، ثم غيّر كلمة المرور من الملف الشخصي

> ملاحظة: مجلد `install/` أُزيل من المشروع بعد الإعداد وحُفظ خارج webroot.

## الوحدات

- الوارد / الصادر / الداخلي مع ترقيم آلي، مرفقات، حالات، أولوية وسرية
- دورة مراجعة واعتماد (مراجعون، معتمدون، تصعيد، قفل تعديل) — [24-approval-workflow.md](24-approval-workflow.md)
- سرية الرؤية والمرفقات (طبقات A/B/C/D + إعدادات وتجاوز لكل عنصر) — [25-confidential-correspondence.md](25-confidential-correspondence.md)
- إحالة بين الأقسام، «يحتاج إجراء»، ربط وارد ↔ صادر
- بريد وواتساب لإرسال الصادر (مع تحييد السري)
- رمز QR للتحقق العام (الرابط يُبنى تلقائياً من الدومين الحالي)
- أرشيف وثائق + سجلات (منح/مشاريع/مالية)، تقارير وتصدير
- مستخدمون وأدوار وصلاحيات دقيقة من الإعدادات
- إعدادات الجهة والمسار والسرية؛ مساعدة مدير النظام من القائمة ← **المساعدة**
- إعادة ضبط بيانات العمل من الإعدادات (مدير النظام فقط)

## الأدوار الأساسية

| الدور | الوصف |
|--------|--------|
| admin | مدير النظام — إعدادات كاملة + تجاوز المسار عند الحاجة |
| communications | اتصالات / إرسال وطباعة حسب الصلاحيات |
| archive | أرشيف وبوابة وارد مركزية (حسب الصلاحيات) |
| department | إدخال ومعالجة حسب القسم |
| viewer | مشاهدة فقط |

الصلاحيات التفصيلية قابلة للضبط لكل دور؛ انظر [14-roles-and-permissions-guide.md](14-roles-and-permissions-guide.md).

## ملاحظات

- عدّل `config/db.php` إذا كانت كلمة مرور MySQL مختلفة
- **رابط النظام يُكتشف تلقائياً** — لا يوجد إعداد يدوي لـ Base URL
- قاعدة البيانات: `dms`
- تسجيل الدخول بالبريد الإلكتروني — رابط نسيت كلمة المرور يعمل بعد تفعيل SMTP
- لا تضع كلمات المرور في ملفات التوثيق؛ غيّر كلمة مرور المدير بعد أول دخول
