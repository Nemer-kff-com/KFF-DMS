# 05 — الخروج التلقائي بعد الخمول

## الهدف

تسجيل خروج المستخدم تلقائياً بعد فترة عدم نشاط، قابلة للتعديل من الإعدادات.

## الإعداد

- الصفحة: `admin/settings.php` → قسم **أمان الجلسة**
- المفتاح: `session_timeout_minutes`
- الافتراضي: **30** دقيقة
- النطاق المسموح: **5 – 1440**

الدالة: `session_timeout_minutes()` في `config/helpers.php`.

## آلية العمل (خادم)

1. عند تسجيل الدخول يُضبط `$_SESSION['last_activity'] = time()`.
2. كل طلب محمي عبر `require_login()` يستدعي `enforce_idle_timeout()`.
3. إذا تجاوز الفرق بين الوقت الحالي و`last_activity` المدة المحددة:
   - يُسجَّل حدث أمني `SESSION_TIMEOUT`
   - يُستدعى `logout_user()`
   - رسالة تحذير: انتهت الجلسة بسبب عدم النشاط
   - توجيه لصفحة الدخول
4. إن لم تنتهِ المدة، يُحدَّث النشاط عبر `touch_user_session()`.

الملفات: `config/auth.php`, `config/security.php`.

## آلية العمل (متصفح)

في الصفحات بعد الدخول، يمرَّر إلى JavaScript:

- `window.__DMS_IDLE_MS__` = المدة بالميلي ثانية
- `window.__DMS_LOGOUT_URL__` = رابط الخروج مع `?reason=timeout`

في `assets/js/app.js`: مؤقت يُعاد ضبطه عند النقر/لوحة المفاتيح/التحريك/التمرير/اللمس.  
عند انتهاء المؤقت → توجيه لـ `auth/logout.php?reason=timeout`.

هذا يغطي حالة بقاء الصفحة مفتوحة دون طلبات للخادم.

## رسائل المستخدم

| المفتاح | المعنى |
|---------|--------|
| `auth.session_timeout` | انتهت الجلسة بسبب الخمول |
| `auth.logout_ok` | خروج يدوي ناجح |

`auth/logout.php` يفرّق بين الخروج العادي وخروج المهلة عبر `reason=timeout`.
