# جهات المراسلة

كل إرسال يعتمد على بطاقة الجهة، لا على إدخال الرقم أو البريد يدوياً في كل معاملة.

من القائمة: **جهات المراسلة** → إضافة أو تعديل.

## الحقول المهمة

| الحقل | الغرض |
|--------|--------|
| الاسم عربي | اسم الجهة في القوائم والمعاملة |
| **اللقب** | سعادة، معالي، صاحب السمو… |
| **الاسم** | اسم المخاطب كما في الخطاب (بدون لقب أو تكريم) |
| **التكريم** | يحفظه الله، يحفظها الله، يحفظهم الله، أو عبارة من القائمة |
| الوظيفة | المسمى في الخطاب والطباعة |
| **رقم الجوال** | لإرسال واتساب (يُضبط تلقائياً للصيغة الدولية عند الحاجة) |
| **البريد الإلكتروني** | لإرسال الخطاب بالبريد |
| هاتف أرضي | اختياري؛ إن لم يُعبَّأ الجوال قد يُستخدم الهاتف إن كان رقم جوال |

## إدارة عبارات التكريم

- **اختيار التكريم على بطاقة الجهة:** لمن يعدّل الجهات (من القائمة أو «بند جديد…» لهذه الجهة فقط).
- **إدارة قائمة العبارات** (إضافة / تعديل / تعطيل): **مدير النظام** من **مسميات القوائم** ثم **التكريم**.
- تعديل عبارة في القائمة يحدّث بطاقات الجهات التي تستخدمها.

## كيف يظهر الاسم في الخطاب

يُجمع تلقائياً: **اللقب + الاسم + التكريم**

مثال: سعادة الأستاذ أحمد العلي يحفظه الله

عند كتابة نص الخطاب (خصوصاً الصادر الجماعي) استخدم أزرار الإدراج:

| الزر | ماذا يُدرج |
|------|------------|
| اللقب | اللقب فقط |
| الاسم | الاسم فقط |
| التكريم | عبارة التكريم فقط |
| الاسم المكرَّم | اللقب والاسم والتكريم معاً |
| الوظيفة | وظيفة المستلم |
| الرقم / التاريخ / الموضوع | بيانات المعاملة |

## ترحيل البيانات القديمة

إذا كان حقل «الاسم» السابق يحتوي اللقب معاً (مثل «سعادة أحمد»)، يُفصل تلقائياً عند الترقية إلى **لقب** + **اسم**.

## قائمة الجهات

| العمود | المحتوى |
|--------|---------|
| **الرقم** | ترتيب العرض في الصفحة (ليس رقم السجل الداخلي) |
| **الاسم** | اللقب فوق الاسم، والتكريم أسفله |
| **جهة العمل** | الوظيفة فوق اسم الجهة |
| **النطاق** | جهة عامة أو جهة قسم (يظهر اسم القسم عند التمرير) |
| **التواصل** | الجوال والبريد؛ فارغ إن لم يُسجَّل شيء |

- تعرض **20 جهة في الصفحة**؛ البحث يشمل الاسم والوظيفة والجوال والبريد والعنوان والملاحظات واسم القسم.
- نفس نص البحث ينتقل إلى **التصدير والطباعة**.

## اختيار الجهة في نموذج المعاملة

الحقل قائمة بحث منبثقة (ليست قائمة منسدلة طويلة). تظهر النتائج عند الفتح أو الكتابة.

- **الصادر** يُحفظ باسم الشخص المخاطب.
- **الوارد** يُحفظ باسم جهة العمل.
