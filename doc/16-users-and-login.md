# 16 — المستخدمون وتسجيل الدخول

## نموذج البيانات (مثل نظام الدعوات)

| الحقل | الغرض |
|-------|--------|
| `email` | **المعرف الفريد للدخول** (UNIQUE) |
| `name_ar` | الاسم العربي — للعرض حسب لغة الواجهة |
| `name_en` | الاسم الإنجليزي — للعرض حسب لغة الواجهة |
| `password` | كلمة المرور |
| `role` | الدور: `admin`, `archive`, `department`, `viewer` |
| `department_id` | القسم (اختياري حسب الدور) |

### ترحيل الأعمدة القديمة

`ensure_users_profile_schema()` في `config/helpers.php`:

- `full_name` → `name_ar`
- `username` → `name_en`
- إزالة UNIQUE عن الاسم الإنجليزي؛ **البريد فقط** فريد

---

## تسجيل الدخول

- **بالبريد الإلكتروني فقط** — `attempt_login()` في `config/auth.php`
- لا يُستخدم `name_en` أو `name_ar` للدخول

---

## النماذج

| الصفحة | ملاحظات |
|--------|---------|
| `auth/profile.php` | المستخدم يعدّل اسمه وبريده؛ علامة * حمراء على **البريد فقط** |
| `admin/users_create.php` / `users_edit.php` | نفس القاعدة عبر `admin/_user_form.php` |
| `admin/users.php` | قائمة المستخدمين |

### التحقق

`dms_validate_user_profile_data()` — يتحقق من:

- الاسم العربي مطلوب
- الاسم الإنجليزي (حروف إنجليزية فقط)
- البريد صالح و**غير مكرر** (مع استثناء المستخدم الحالي عند التعديل)

دوال مساعدة:

- `dms_normalize_user_email()` — توحيد البريد
- `dms_user_owns_email()` — السماح بالاحتفاظ بنفس البريد عند الحفظ
- `user_display_name()` — عرض الاسم حسب لغة الواجهة
