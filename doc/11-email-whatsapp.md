# 11 — إعدادات البريد وواتساب

النظام مستقل. تُضبط القنوات من داخله فقط.

## البريد (SMTP)

المسار: الإدارة → إعدادات البريد.

هناك مستويان:

1. **حساب النظام (عام):** نسيان كلمة المرور وإشعارات النظام، واحتياطي لإرسال الخطابات.
2. **حساب القسم:** اختياري. إذا كان مفعّلاً يُرسل صادر ذلك القسم من صندوقه. وإلا يُستخدم حساب النظام.

لضبط قسم: اختر القسم من قائمة النطاق، أدخل SMTP، فعّل، ثم اختبر. لـ Office 365 يُفضّل تطابق المستخدم مع البريد المرسل.

خطوات الحساب:

1. أدخل الخادم والمنفذ والتشفير (غالباً 587 + TLS أو 465 + SSL).
2. اسم المستخدم وكلمة المرور (لحساب Office 365 غالباً كلمة مرور تطبيق).
3. البريد المرسل واسم المرسل.
4. فعّل الإرسال.
5. أرسل اختباراً إلى بريدك.

مكتبة الإرسال محلية: `lib/PHPMailer/` داخل هذا المشروع.

## واتساب

حساب **واحد** للمؤسسة. لا يُقسَّم على الأقسام لأن توثيق واتساب بيزنس يتم مرة واحدة على رقم/حساب المزود.

المسار: الإدارة → إعدادات واتساب.

المزودون المدعومون:

- Twilio
- Meta Cloud API
- مزود يدوي (HTTP JSON)

خطوات عملية:

1. اختر المزود وأدخل بياناته.
2. اترك كلمات السر فارغة بعد الحفظ للإبقاء على القيمة الحالية.
3. ضع قوالب الخطاب العربي/الإنجليزي إن كان المزود يتطلب قالباً معتمداً (Meta وغالباً Twilio).
4. مفتاح الدولة الافتراضي `966` لتحويل `05xxxxxxxx`.
5. فعّل الإرسال ثم أرسل اختباراً إلى جوالك.

## الجاهزية

في صفحة الإعدادات يظهر ملخص: جاهز / معطّل / بيانات ناقصة.

من صفحة الصادر:

- إن لم تكن القناة مفعّلة يظهر تنبيه لضبط الإعدادات.
- إن كانت مفعّلة لكن الجهة بلا بريد/جوال يُطلب استكمال بطاقة الجهة.

## المعاملات السرية والقنوات الخارجية

عند تفعيل الوضع المحرَّر (`conf_external_notify_mode=redacted` — الافتراضي في إعدادات السرية):

| القناة | السلوك |
|--------|--------|
| بريد/واتساب إرسال الصادر | موضوع/نص محايد (رقم/نوع)؛ **بدون** نص الخطاب الكامل و**بدون** مرفقات سرية |
| إشعارات النظام بالبريد | لا تُرسل لمن لا يرى المعاملة؛ والجسم بلا صفوف موضوع/جهة حساسة |
| إشعار داخل النظام | نفس تصفية المستلمين + اختزال النص عند الحاجة |
