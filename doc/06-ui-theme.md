# 06 — الواجهة والثيم وتنبيهات النظام

## الهوية البصرية

- ملف الثيم: `assets/css/app.css`
- ألوان أساسية تقريباً: أخضر KFF `#0b5130`، أزرق رمادي `#3B4F6E`، خلفية كريمية
- خط GretaArabic + Tajawal
- تخطيط موحّد: `page-header` + `card-panel`

عرض المحتوى متوافق مع الهيدر (حد أقصى تقريباً 1400px).

## القائمة الجانبية

- عرض أضيق (`--sidebar-width` حوالي 228px)
- شعار أكبر في المنتصف (~80px)
- اسم الجهة/النظام في المنتصف تحت الشعار
- مجموعات قابلة للطي عبر `render_nav_group()`:
  - **المعاملات:** وارد، صادر، إحالات، أرشيف، وثائق
  - **الإعدادات:** جهة، بريد، مستخدمون، أقسام، قوائم، سجلات، جلسات
- لوحة التحكم والتقارير روابط منفردة
- منطق الطي في `assets/js/app.js`

## لوحة التحكم

- بطاقات إحصائية قابلة للنقر
- إجراءات سريعة
- صفوف جداول قابلة للنقر للانتقال لعرض المعاملة

## SweetAlert2

نفس أسلوب نظام الدعوات (نافذة مركزية، ليست toast جانبية فقط للفلاشات).

| الملف | الدور |
|--------|------|
| `assets/css/swal-dms.css` | ثيم DMS |
| `assets/js/swal-dms.js` | مساعدات العرض |
| `includes/swal_boot.php` | ربط الفلاش والتأكيدات |

- رسائل `flash()` تظهر عبر SweetAlert
- التأكيدات عبر الخاصية `data-confirm` على الأزرار/النماذج
- لون العلامة التجارية للتنبيهات: `#3B4F6E`
- تم إلغاء فلاش الترحيب بعد تسجيل الدخول الناجح

## كسر التخزين المؤقت للأصول

في `includes/head_assets.php` و`footer.php` تُلحق إصدارات مثل `?v=16` لملفات CSS/JS عند التحديث.

## صفحة الإعدادات (تنسيق)

- رأس بأزرار: إعدادات البريد + حفظ
- عمود رئيسي للإعدادات + عمود جانبي ثابت للشعار/المعاينة
- مفاتيح العرض كقائمة مرتبة (ليست جدولاً مكتظاً)
- شريط حفظ ثابت أسفل الصفحة
