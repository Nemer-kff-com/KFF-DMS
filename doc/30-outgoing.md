# الصادر

خطاب إلى جهة خارجية.

## مفرد

1. **الصادر** ← صادر جديد
2. الموضوع والجهة والقسم والتاريخ
3. احفظ ثم أرسل أو اطبع أو سجّل التسليم

## جماعي

1. **الصادر** ← صادر جماعي
2. اختر المستلمين ثم أصدر للجميع
3. لكل مستلم رقم خاص؛ بعدها إرسال أو طباعة

## بعد الإصدار

- إلكتروني ← إرسال بريد / واتساب
- ورقي ← طباعة وتسجيل الاستلام
- إن لزم ← تأكيد حضور أو إلغاء / سحب
